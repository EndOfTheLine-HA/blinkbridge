# Distribution status

The upstream `roger-/blinkbridge` repository does not currently include an
explicit software license. A public GitHub repository is not automatically
open source, and the absence of a license does not grant redistribution or
derivative-work rights.

This working branch is therefore a private release candidate. Do not publish,
distribute, or label it as open source until the upstream copyright holder adds
a license or gives suitable written permission. When that happens, preserve
the upstream copyright and license notices and add a license for original
contributions only if the granted terms permit it.
